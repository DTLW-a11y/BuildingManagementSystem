# 项目概要介绍

## 1. 项目名称

建筑能源智能管理系统

## 2. 团队信息

团队名称：萌新下山队

团队成员：林子为、秦迎彬、张奕弛、韩湘美蓓

学校：电子科技大学

指导老师：张翔

## 3. 项目背景

在全球气候变化与中国“双碳”战略背景下，建筑行业运行阶段碳排放占全国总量20%以上，是落实碳达峰、碳中和目标的关键领域。当前建筑能源管理存在突出痛点，运维高度依赖人工经验、知识传承困难、响应滞后，且能耗数据分散、格式不统一，查询统计效率低，缺乏智能化分析手段，传统管理模式已难以适配行业绿色低碳发展需求。人工智能大模型技术的快速迭代，为破解上述痛点提供了核心支撑。中建八局第二建设有限公司作为合作支持单位，开放真实应用场景与运维资源，提供技术与实践支撑。基于此，本次项目聚焦行业需求与技术趋势，研发建筑能源智能管理系统，依托大模型技术构建一体化解决方案，破解行业痛点，助力建筑行业绿色转型。

## 4. 项目目标

依托人工智能大模型的自然语言交互、数据挖掘与智能推理能力，整合建筑能耗数据资源，构建一套适配实际建筑能源管理场景、可落地的智能管理系统，破解当前建筑能源管理中数据分散、运维依赖人工、知识传承困难等核心痛点，实现能耗数据高效处理、查询统计自动化、运维决策智能化，为建筑能源管理提供精准、高效的智能化解决方案，助力“双碳”战略落地，同时衔接企业实际应用需求，为建筑行业绿色低碳高质量发展提供技术支撑。

## 5. 核心功能

| **功能** | **内容**                                                     |
| -------- | ------------------------------------------------------------ |
| 数据层   | 数据集构建、清洗、导入接口                                   |
| 查询统计 | MCP协议接口、3类统计分析（时段汇总/COP计算/异常分析）、2种可视化图表、报表导出 |
| 智慧运维 | 领域知识库 + RAG问答，支持能耗查询、设备状态查询、异常原因分析、故障诊断 |
| 系统集成 | Vue.js前端 + Python后端，界面简洁，全流程交互                |

## 6. 技术栈

| 技术方向 | 工具                                                         |
| -------- | ------------------------------------------------------------ |
| 前端     | Vue 3 +  Vite + ECharts                                      |
| 后端     | Python 3.8 + FastAPI + Uvicorn + Pandas + Openpyxl           |
| 数据库   | SQLite +  SQLAlchemy ORM                                     |
| 轻量LLM  | Ollama + Qwen / LLaMA3 + RAG（知识增强）+ Prompt  Engineering + Hybrid推理 |
