# 设备运维手册

## 空调系统运维

### 日常检查项目
1. **冷水机组**：每日检查运行压力、温度、电流是否正常
2. **冷却塔**：检查风机运行、补水水位、冷却水温度
3. **水泵**：检查运行电流、振动、噪音
4. **末端设备**：检查风机盘管运行、过滤网清洁度

### 常见故障及处理

#### 故障1：制冷效果差 / COP偏低
- **症状**：室内温度降不下来，COP低于2.5
- **可能原因**：
  1. 冷媒不足或泄漏
  2. 冷凝器脏堵
  3. 膨胀阀失调
  4. 蒸发器结霜
- **处理步骤**：
  1. 检查冷媒压力（正常高压1.5~1.8MPa，低压0.4~0.6MPa）
  2. 清洗冷凝器翅片
  3. 检查膨胀阀开度
  4. 融霜处理

#### 故障2：供回水温差异常
- **症状**：供回水温差 < 2°C 或 > 10°C
- **温差过小原因**：水流量过大、负荷过小
- **温差过大原因**：水流量不足、管路堵塞、水泵故障
- **处理步骤**：
  1. 检查水泵运行状态
  2. 调节平衡阀
  3. 检查管路是否有堵塞
  4. 确认负荷分配是否合理

#### 故障3：系统噪音异常
- **症状**：异常振动或噪音
- **可能原因**：水泵汽蚀、管道共振、轴承损坏
- **处理步骤**：
  1. 检查系统水压，排除汽蚀
  2. 检查管道支架和减振垫
  3. 轴承润滑或更换

### 定期维护计划

| 维护周期 | 维护内容 |
|----------|----------|
| 每周 | 检查设备运行参数，清理设备表面灰尘 |
| 每月 | 检查过滤网，清洗风机盘管，检查冷却水水质 |
| 每季度 | 全面检查管路系统，校验温度传感器，清洗冷凝器 |
| 每年 | 大修，更换易损件，检测冷媒量，系统压力测试 |

## 电气系统运维

### 能耗监测系统

#### 正常运行标准
- 数据采集间隔：1小时（可调）
- 传感器精度：±1%
- 通信成功率：≥99%

#### 常见故障

##### 故障1：数据缺失/断点
- **原因**：通信中断、传感器故障、系统断电
- **处理**：
  1. 检查网络连接
  2. 重启数据采集器
  3. 检查传感器供电

##### 故障2：数据异常（跳变、持续为0）
- **原因**：传感器损坏、接线松动、EMI干扰
- **处理**：
  1. 检查传感器接线
  2. 用万用表核验实际值
  3. 加装滤波装置

### 配电系统维护
1. **定期巡检**：每月检查配电柜、开关状态
2. **绝缘测试**：每年进行绝缘电阻测试
3. **负荷均衡**：确保三相负荷平衡，不平衡度 < 15%

## 照明系统运维

### 节能控制策略
1. 时间表控制：按作息时间自动开关
2. 区域控制：按楼层/区域独立控制
3. 感应控制：人体红外感应，无人自动关闭（5分钟延时）

### 维护要点
- 定期更换老化灯管（亮度降至70%以下即更换）
- 清洁灯具（每半年）
- 检查控制开关、感应器工作状态

---

## 故障报告流程

1. **发现异常** → 记录异常时间、位置、现象
2. **初步判断** → 根据症状参考本手册排查
3. **上报** → 通过运维平台提交工单
4. **专业维修** → 联系专业人员处理
5. **验收** → 确认故障排除后关闭工单
6. **记录归档** → 将故障原因和处理方法记录到知识库
