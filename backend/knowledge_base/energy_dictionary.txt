# 能耗数据字典与术语解释

## 基础概念

### 电力能耗 (Power Consumption)
- 单位：kWh（千瓦时）
- 定义：建筑在单位时间内消耗的电能总量，包括照明、空调、设备等所有电气设备用电
- 正常范围：
  - 教学楼：20~180 kWh/小时
  - 办公楼：15~120 kWh/小时
  - 图书馆：30~200 kWh/小时
  - 实验楼：25~250 kWh/小时
- 异常判断：超过正常值1.5倍或深夜时段（22:00-6:00）用电量异常高时视为异常

### 水耗 (Water Consumption)
- 单位：m³（立方米）
- 定义：建筑在单位时间内的用水总量，包括生活用水、冷却塔补水等
- 正常范围：0.1~5.0 m³/小时（视建筑规模）

### 空调系统能耗 (AC Power Consumption)
- 单位：kWh
- 定义：空调（HVAC）系统运行消耗的电能，通常占总能耗的40~65%（夏季）或35~55%（冬季）
- 影响因素：室外温度、湿度、人员密度、空调设定温度

### COP (Coefficient of Performance, 能效比)
- 无量纲
- 定义：空调系统的能效比，表示每消耗1kWh电能可产生多少kWh的制冷/制热量
- 计算公式：COP = 制冷（热）量 / 输入电功率
- 参考值：
  - 优秀：COP ≥ 3.5
  - 良好：3.0 ≤ COP < 3.5
  - 一般：2.5 ≤ COP < 3.0
  - 较差：COP < 2.5
- 影响因素：室外温度越高（夏季制冷），COP越低；室外温度越低（冬季制热），COP越低

### 空调出水温度 (AC Supply Temperature)
- 单位：°C
- 制冷工况：通常为7~12°C
- 制热工况：通常为45~55°C

### 空调回水温度 (AC Return Temperature)
- 单位：°C
- 制冷工况：通常比出水温度高4~7°C（即12~18°C）
- 制热工况：通常比出水温度低5~10°C（即35~50°C）
- 供回水温差过小：可能表示流量过大或负荷过小
- 供回水温差过大：可能表示流量不足或堵塞

### 人员密度 (Occupancy Density)
- 单位：人/100㎡
- 影响：人员越密集，散热量越大，空调负荷越高
- 参考值：办公楼8~15人/100㎡（工作时间），教学楼10~20人/100㎡（上课时间）

## 能耗异常类型

### 能耗异常偏高
- 描述：用电量超过正常值的1.5倍以上
- 可能原因：
  1. 设备故障（如空调短路、漏电）
  2. 未关灯、空调等设备
  3. 非工作时间有人员活动
  4. 传感器故障导致数据失真
- 处理建议：立即检查各楼层用电设备，排查异常设备

### 超额用电
- 描述：用电量超过建筑额定功率上限
- 可能原因：
  1. 大型实验设备同时开启
  2. 临时加装大功率电器
  3. 电表故障
- 处理建议：检查大功率设备，联系电力管理部门

### 深夜用电异常
- 描述：22:00~6:00时段用电量异常偏高
- 可能原因：
  1. 照明设备未关闭
  2. 空调未关闭（冬夏季尤其注意）
  3. 有未报备的夜间活动
  4. 设备自动运行程序异常
- 处理建议：设置夜间自动断电程序，检查楼控系统

## 节能建议

### 空调节能
- 夏季室内设定温度不低于26°C，冬季不高于20°C
- 过渡季（15~25°C）优先使用自然通风
- 定期清洗过滤网，保持COP在3.0以上
- 实施分时分区控制，减少非使用区域空调运行

### 照明节能
- 推广LED灯具，降低单位面积照明能耗
- 安装人体感应或光线感应控制
- 减少非工作时段照明

### 设备节能
- 办公设备下班后关机或休眠
- 实验室大型设备按需启动
- 电梯实施节能运行模式
