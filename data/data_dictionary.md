# 能耗数据集数据字典

## 数据集概述

本数据集为建筑能源智能管理系统模拟能耗数据集，包含5栋建筑（教学楼A/B、办公楼、图书馆、实验楼）
2024年全年（按小时粒度）的能耗监测数据，共计约1500条记录。

## 字段说明

| 字段名 | 中文名称 | 数据类型 | 单位 | 说明 |
|--------|----------|----------|------|------|
| record_id | 记录编号 | String | - | 唯一标识，格式：R+6位数字 |
| building_id | 建筑编号 | String | - | B001~B005 |
| building_name | 建筑名称 | String | - | 教学楼A/B、办公楼、图书馆、实验楼 |
| building_type | 建筑类型 | String | - | 教学楼/办公楼/图书馆/实验楼 |
| monitor_time | 监测时间 | DateTime | - | 格式：YYYY-MM-DD HH:MM:SS，精确到小时 |
| year | 年 | Integer | - | 监测年份 |
| month | 月 | Integer | - | 监测月份（1-12） |
| day | 日 | Integer | - | 监测日期（1-31） |
| hour | 时 | Integer | - | 监测小时（0-23） |
| power_consumption | 电力能耗 | Float | kWh | 该小时内总电力消耗 |
| water_consumption | 水耗 | Float | m³ | 该小时内用水量 |
| ac_power_consumption | 空调系统能耗 | Float | kWh | 该小时内空调系统耗电量 |
| ac_supply_temp | 空调出水温度 | Float | °C | 空调系统冷/热水出水温度 |
| ac_return_temp | 空调回水温度 | Float | °C | 空调系统冷/热水回水温度 |
| cop | COP值 | Float | - | 空调系统能效比（制冷/制热量/输入功率） |
| env_temperature | 环境温度 | Float | °C | 室外环境温度 |
| env_humidity | 环境湿度 | Float | %RH | 室外环境相对湿度 |
| occupancy_density | 人员密度 | Float | 人/100㎡ | 建筑内人员密度 |
| device_id | 设备编号 | String | - | 能耗监测设备唯一标识 |
| device_status | 运行状态 | String | - | 正常/异常 |
| anomaly_flag | 异常标志 | Integer | - | 0=正常，1=异常 |
| anomaly_reason | 异常原因 | String | - | 异常时的描述，正常时为空 |

## 数据质量说明

- 约6.6%的记录标记为异常，模拟真实场景中的能耗异常情况
- 异常类型包括：能耗异常偏高、超额用电、深夜用电异常
- 数据经过合理性校验，温度、湿度、能耗等数值均在合理范围内
- 时间粒度：小时级，覆盖2024年全年（约8760小时/建筑）

## 能耗参考值

| 建筑类型 | 正常电力能耗范围(kWh/h) | 备注 |
|----------|------------------------|------|
| 教学楼 | 20~180 | 上课期间较高 |
| 办公楼 | 15~120 | 工作日白天较高 |
| 图书馆 | 30~200 | 开放时间较高 |
| 实验楼 | 25~250 | 实验时段较高 |

## COP值参考

- 夏季制冷：COP 3.0~4.0（外温越高，COP越低）
- 冬季制热：COP 2.5~3.5（外温越低，COP越低）
- 过渡季节：COP 2.8~3.5

## 数据来源说明

本数据集为基于真实建筑能耗规律通过模拟生成，仅用于算法研究与系统开发，不代表真实建筑数据。
