# 建筑能源智能管理系统 用户使用手册

## 1. 文档目的
本手册用于指导用户完成系统安装与部署、日常功能操作、常见故障排查，适用于演示环境、课程实践环境和轻量化本地部署环境。

## 2. 系统概览
建筑能源智能管理系统（BEIMS）由以下部分组成：
- 后端：FastAPI + SQLAlchemy + SQLite
- 前端：HTML + Vanilla JS + ECharts
- 数据：CSV 文件导入与本地数据库存储
- 智慧运维：规则检索 + 数据上下文问答

系统默认访问地址：
- Web 页面：http://localhost:8000
- API 文档：http://localhost:8000/docs
- 健康检查：http://localhost:8000/health

## 3. 安装与部署

### 3.1 环境要求
- 操作系统：Windows / macOS / Linux
- Python：3.10 及以上（推荐 3.11 或 3.13）
- pip：可用
- 浏览器：Chrome/Edge/Firefox 最新版

### 3.2 方式一：一键启动（推荐）
在项目根目录执行：

```bash
bash start.sh
```

脚本自动完成：
1. 检测可用 Python（自动处理 Git Bash / WSL 场景）
2. 安装后端依赖
3. （可选）构建前端资源
4. 启动 Web 服务（8000 端口）

注意：系统不再自动生成或自动导入数据。请在启动后进入“数据管理”页面手动上传 CSV 文件。

### 3.3 方式二：手动部署
在项目根目录执行：

```bash
# 1) 安装依赖
py -m pip install -r backend/requirements.txt

# 2) 启动服务
py -m uvicorn app:app --app-dir backend --host 0.0.0.0 --port 8000 --reload
```

说明：如系统未识别 py 命令，可替换为 python 或 python3。

### 3.4 启停与验证
- 启动后验证：浏览器访问 http://localhost:8000/health，返回 status=ok 即正常。
- 停止服务：在运行窗口按 Ctrl + C。
- 强制停止（Windows）：

```powershell
netstat -ano | findstr :8000
taskkill /PID <PID> /F
```

## 4. 各模块操作流程

### 4.1 仪表盘模块
目标：快速查看系统总体运行状态。

操作流程：
1. 打开首页后默认进入“仪表盘”。
2. 查看 KPI 指标：总记录数、总电耗、总水耗、平均 COP、异常数、异常率。
3. 查看图表：建筑能耗分布饼图、近期趋势折线图。
4. 点击“刷新数据”更新页面。

建议：每次导入新数据后先刷新仪表盘，确认全局指标是否变化。

### 4.2 数据管理模块
目标：导入 CSV 数据并核验数据集状态。

操作流程：
1. 切换到“数据管理”。
2. 点击“选择文件”或直接拖拽 CSV 文件到上传区域。
3. 观察上传结果：新增条数、重复跳过条数、错误信息。
4. 点击“刷新统计”查看：总记录数、时间范围、各建筑记录分布。

注意事项：
- CSV 字段需与数据字典一致，参考 data/data_dictionary.md。
- 同一主键记录会被识别为重复并跳过。

### 4.3 数据查询模块
目标：按业务条件检索明细记录并导出。

操作流程：
1. 切换到“数据查询”。
2. 设置筛选条件（可组合）：建筑、类型、时间段、年份、月份、设备状态、仅异常。
3. 点击“查询”查看分页结果。
4. 点击“导出 CSV”导出当前筛选条件对应数据。
5. 点击“重置”清空条件重新检索。

建议：
- 优先设置时间范围再查询，可显著提升定位效率。
- 异常排查场景建议开启“仅显示异常”。

### 4.4 统计分析模块
目标：完成趋势分析、能效评估与异常识别。

#### 4.4.1 时段汇总分析
1. 选择分组方式（按月/按天/按小时/按建筑）。
2. 可选年份与建筑过滤。
3. 点击“分析”查看柱状图与明细表。

#### 4.4.2 COP 能效分析
1. 选择年份、建筑。
2. 点击“分析”查看 COP 趋势与统计说明。
3. 关注低 COP 时段，结合设备状态进一步排查。

#### 4.4.3 异常分析
1. 选择年份、月份。
2. 点击“分析”查看异常柱状图和原因分布饼图。
3. 结合下方摘要制定运维策略。

### 4.5 智慧运维模块
目标：通过自然语言进行运维问答和建议获取。

操作流程：
1. 切换到“智慧运维”。
2. 可先选择建筑过滤范围。
3. 输入问题并发送，或使用快捷问题模板。
4. 阅读系统回答中的结论、依据和建议。

推荐提问方式：
- B003 近三个月异常率是否上升？
- 教学楼 A 的 COP 是否低于建议值？
- 请给出图书馆空调系统节能建议。

## 5. 常见问题排查

### 5.1 启动时报错 No module named pip
原因：当前 Python 环境未安装 pip 或调用到错误解释器。

处理：
```bash
py -m ensurepip --upgrade
bash start.sh
```

### 5.2 安装依赖时报 pydantic-core / rustup / PermissionError
原因：旧版本 pydantic 在 Python 3.13 下触发本地编译并调用 Rust 工具链。

处理：
- 使用项目 requirements 固定版本重新安装。
- 执行：

```bash
py -m pip install -r backend/requirements.txt
```

### 5.3 启动时报 SQLAlchemy AssertionError
原因：SQLAlchemy 版本与 Python 3.13 兼容性问题。

处理：
- 保持 requirements 中 SQLAlchemy 为 2.0.38 或更高兼容版本。
- 重新安装依赖后再启动。

### 5.4 端口 8000 被占用
现象：启动提示 Address already in use。

处理（Windows）：
```powershell
netstat -ano | findstr :8000
taskkill /PID <PID> /F
```

### 5.5 页面可打开但无数据
可能原因：数据库为空或未导入数据。

处理：
1. 进入“数据管理”上传 data/energy_data.csv。

### 5.6 上传 CSV 失败
排查顺序：
1. 确认文件扩展名为 .csv。
2. 确认编码和字段名与数据字典一致。
3. 检查时间、数值字段是否存在非法字符。
4. 在页面导入结果中查看错误信息前几条进行修复。

## 6. 运行维护建议
- 建议定期备份数据库文件：energy_management.db。
- 生产环境建议将 SQLite 替换为 PostgreSQL，并加上反向代理。
- 建议通过任务计划定时归档 CSV 与日志。
- 重要操作前（批量导入、清库）先做备份。

## 7. 支持与扩展
- API 调试与联调：访问 /docs。

- 智慧问答能力可在 backend/routers/chat.py 中扩展为真实 LLM 接入。
